# CleanRoute landing page

Public URL: https://cleanroute.trigenys.com/

The landing page is a static, single-file site adapted from the approved Stitch design.

## Product-accuracy rules

- Core MVP claims must match the Android app.
- Mapping/route optimization must be presented as optional/prototype capability until enabled in product.
- The site must not claim that a pilot request was submitted unless a real backend/action exists.
- GitHub links should point to the CleanRoute repository or Project Board.
- Canonical domain is `cleanroute.trigenys.com`.

## Deployment

Production is published from the `gh-pages` branch with a `CNAME` file for `cleanroute.trigenys.com`.
